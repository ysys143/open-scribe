# Scribe

현재 CLI는 Homebrew 0.2.4의 입력·출력 계약에 모델 연결만 갱신한 버전이다.

```sh
scribe "<local audio or YouTube URL>"
openscribe ls  # 최근 10건
scr ls 20      # 최근 20건
```

- 일반 녹취 요청은 전사와 기본 요약까지 처리한다. 사용자가 전사만 요청할 때 `--no-summary`를 쓴다.
- 실행한 CLI가 출력하는 제목·저장 경로를 사용한다. 제목 기반 TXT와 `_summary.txt`가 생성되고
  기존 Downloads 설정에 따라 같은 파일명으로 복사된다. stdout을 JSON으로 가정하지 않는다.
- 모델은 settings.json의 stages 모델·options를 따른다. 오류·속도·비용 때문에 모델이나
  음성 전사를 자막 추출로 바꾸지 않는다. `--engine`은 사용자가 선택한 경우만 지정한다.
- 현재 CLI에 `transcribe`, `jobs`, `auth`, `review`, `dashboard`, `--json`, `--quiet`는 없다.
  옵션이 불확실하면 한 번 `scribe --help`를 확인한다. `--no-stream`은 본문 출력을 끄는 옵션이다.
- 일반 옵션·경로는 settings.json만 읽는다. copy_to_path가 복사 위치이며 null이면 복사하지 않는다. `config show`·`config validate`로 공개 설정을 확인할 수 있다.
- 인증은 settings.json에 명시한 키 파일 또는 명시적 인증 환경변수에서만 읽는다. .env는 자동 로드하지 않는다.
  키 값은 조회·출력·복사하지 않는다. Keychain 등록·전역 export로 보완하지 않는다.
- 유료 호출은 기존 승인·상한 안에서만 실행한다. 오류나 결과가 불명확한 호출을 자동 재시도하거나
  `--force`로 중복 실행하지 않는다. 실행 중인 작업을 남긴 채 완료라고 보고하지 않는다.

## 화자와 최종 정리

화자 분리 모델의 실제 레이블이 있고 요약을 실행하면, 같은 요약 요청에서 명시적 자기소개 근거가 있는 이름을 자동 반영한다. 원본은 제목_raw_<hash>.txt, 근거는 제목_speaker_names.json에 보존한다. 이 결과는 추정이며 사용자 확인이 아니다. 추가 식별 LLM 호출은 자동으로 하지 않는다.

전사 텍스트에서 자기소개·직접 호명 등 확실한 근거를 먼저 확인한다. 추정과 확정을 구분한다.
사용자 확인이 필요하면 여러 판단에 도움이 되는 대표 발화를 묶어 선택형으로 질문하고
모름·다른 사람 가능성을 남긴다. 원본 ASR을 보존하고 확인된 화자·교정은 별도 최종 파일에 반영한다.
추가 요약은 현재 에이전트가 작성하며 전체 전사를 별도 LLM에 자동으로 재입력하지 않는다.

최종 파일·요약의 실제 경로와 미확정 부분을 알린다. 사용자가 저장한 화자 정보 등을 갱신했다면
반드시 `PATH에 있는 메모리를 갱신했습니다`라고 절대 경로를 포함해 안내한다.
Notion 등 외부 게시 요청은 명시된 승인 범위를 따르고 실제 게시 결과를 확인한다.
