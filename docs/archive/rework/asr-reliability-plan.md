# ASR 정확도·화자 연결 복구 계획

## 1. 목표와 현재 결함

목표는 CSNL-1104에서 드러난 오인식을 재현하고, 정상 호출·짧은 청크·실패 검출·검증된 모델 선택을 갖춘 경로로 전체 파일을 다시 처리하는 것이다. 패키지 설치, 자원 자격, 전사 정확도는 서로 다른 판정으로 기록한다.

확인된 사실:

- 120초 고정 경계 14:00에서 문제 표현이 발생했다. 앞뒤 문맥 재전사도 정답을 확정하지 못했다.
- Qwen 기본 호출은 최대 8192 tokens이며 반복 방어 설정이 전달되지 않았다. 512 tokens와 penalty 1.1 실험에서 반복 폭주는 멎었지만 오인식은 남았다.
- Whisper native MLX checkpoint는 정식 어댑터에서 config·alignment_heads·processor 처리가 맞지 않았다. 일회성 진단의 실행 성공을 제품 지원으로 취급하지 않는다.
- 마지막 1.4초 빈 전사를 실패로 처리했다. ASR 언어 누락과 본문/단어 응답 불일치로 화자 연결·자막도 partial이다.
- 올바른 OpenRouter STT catalog 필터로 현재 모델 30개가 조회됐다. 기존 모델 선정은 이 후보군을 충분히 검증하지 못했다.

## 2. 작은 표본에서 먼저 복구

CSNL에서 12개 클립, 총 약 8분의 고정 평가 묶음을 만든다. 문제 경계, 일반 대화, 맞장구·겹침, 작은 목소리, 숫자·고유명사·부정문, 첫 구간과 마지막 꼬리를 포함한다. 모델·변환·decoder 옵션·원본 hash와 범위를 고정하고 비교용과 보류용을 분리한다. 정답은 원음 검수로 작성하며 모델 다수결이나 LLM 문맥 교정을 정답으로 사용하지 않는다. 직접 청취 검수가 불가능한 항목은 사용자 확인이 필요한 항목으로 남기고 점수를 만들지 않는다.

먼저 정식 코드 경로를 고친다. 언어 코드는 내부 공통 표현에서 모델별 형식으로 변환한다. Qwen과 Whisper의 공통 전처리는 16kHz mono float32로 검증하고 각 모델의 native loader·tokenizer·processor·checkpoint 버전을 고정한다. Whisper의 alignment_heads는 학습 가중치와 분리해 읽되 나머지 가중치는 strict 검사한다. 임시 monkeypatch·절대 경로 진단 스크립트는 제품 경로에 포함하지 않는다.

settings.json의 ASR options에 decoding과 chunking을 추가한다. 로컬 기본값은 temperature 0, 30초 입력당 max_tokens 1024이며 repetition_penalty는 모델별 지원을 검증해 전달한다. Qwen은 1.0/1.1/1.15를 고정 비교한다. 앞 실험의 1.1을 정답 설정으로 확정하지 않는다. 토큰 상한 도달·종료 이유·반복을 기록하고, 상한 도달은 정상 종료로 처리하지 않는다.

## 3. 모델 선정과 청크·상태 처리

전체 30개 STT 모델의 활성 endpoint, 한국어 지원, 시간 정보·화자 반환, 과금 단위를 표로 확인한다. 실제 비교는 현재 Nemotron을 기준선으로 두고 OpenRouter의 Whisper large-v3-turbo, Qwen3-ASR-1.7B, ElevenLabs Scribe v2로 시작한다. 공급자 문서와 공개 metadata로 요청·과금 계약을 확인한 후보만 호출한다. 모든 원격 호출은 기존 공유 원장의 남은 $10 안에서 예약·정산한다. 비교 표본을 통과하지 않은 모델로 60분 전체를 반복 실행하지 않는다.

모델 선택은 한국어 CER, 숫자·부정·고유명사 검수, 반복·누락, 화자/시간 계약을 우선한다. 그 다음 실행시간과 비용으로 동률을 판단한다. 기본 모델 변경은 선정 결과와 함께 settings.json 한 곳에만 반영한다. 로컬 모델은 보조이며 자원·실행 실패 시 원격 결과를 보존한다.

청크 기본값은 core 30초, hard maximum 45초, 좌우 문맥 2초다. 기존 VAD 경계를 쓸 수 있으면 25–35초 범위의 발화 사이를 선택하고, 없으면 고정 core를 사용한다. 5초 미만 꼬리는 앞 청크에 합치며 최대 길이를 넘으면 마지막 두 core를 재분할한다. 원본 시간과 읽은 문맥 범위를 별도 저장한다. 경계 밖 문맥의 단어를 중복 출력하지 않고, 시간 정렬이 없는 응답은 단순 문자열 유사도로 지우지 않는다.

원격 빈 응답을 곧바로 무음으로 간주하지 않는다. 로컬 음성 구간과 에너지 검사도 음성 부재를 지지하면 no_speech, 음성이 있거나 판단 불가면 needs_review로 남긴다. 같은 입력의 무한 재시도와 미확정 과금 재요청을 금지한다.

## 4. 품질 검사와 화자 연결

구조 검증과 품질 검증을 분리한다. 응답에는 raw text/words, canonical text, 언어와 출처, decoder 종료 상태, 품질 플래그를 보존한다. 범위는 accepted / needs_review / rejected / no_speech로 판정한다. 반복·누락·숫자/부정 변화·본문과 단어 불일치를 탐지하되 탐지된 텍스트를 임의 삭제하거나 문맥으로 대체하지 않는다. 무의미한 반복의 자동 검출은 같은 8자 이상 구절의 연속 4회부터 검토 대상으로 삼고, 정상 반복 발화 fixture를 함께 검증한다.

canonical 본문과 정확히 연결되는 단어만 확정 화자 표기를 한다. 단어 응답과 본문이 다르면 짧은 청크의 canonical 본문을 다시 정렬한다. 겹침은 실제 화자 구간의 시간 교집합으로 계산하고, 단순 화자 전환 경계와 구분한다. 불확실한 경계·동시 발화에는 unknown을 남긴다. 숫자·소수점·부정문·구간을 버려 화자 연결률을 높이지 않는다.

정렬 입력은 문맥을 포함해 49초 이하로 제한하고 한국어 실제 표본으로 현행 3GiB 자격을 다시 확인한다. 완료되지 않은 정렬은 SRT/VTT 성공으로 표시하지 않는다. raw 결과·검토 항목·화자 시간 구간·확정된 출력은 구분해 보존한다. 요약은 미해결 구간을 표시하고 그 구간에서 숫자·결정을 확정하지 않는다.

## 5. 단계별 합격과 배포

1. **재현·호출 검사:** 문제 경계, 언어 매핑, native Whisper loading, decoder 인자 누락, 상한 도달·반복·빈 응답을 RED로 재현하고 정식 어댑터에서 통과시킨다. 임시 진단 패치로 통과했다고 보고하지 않는다.
2. **고정 평가:** 제안 합격선은 검수 reference 표본에서 공백 제외 CER 10% 이하, 기존 기준선보다 개선, 필수 숫자·부정문 검수 통과다. 정답 없는 항목은 합격 점수에서 빠뜨려 유리하게 계산하지 않는다. 모델·parameter 선정 뒤 보류 표본을 한 번 평가한다.
3. **CSNL 전체 재처리:** 작은 표본을 통과한 한 경로로 60분 파일을 다시 처리한다. 음성 구간의 누락·중복, unresolved 청크, 반복 폭주, 자막 정렬 불일치를 집계하고 기존 결과와 비교한다. 실제 사람 수를 음성 군집 수만으로 확정하지 않는다.
4. **회귀·실패 검사:** 원본 보존, stage cache, 재개, 예산, local OOM/timeout, unknown 과금 보호, 설정 우선순위를 검사한다. 결함 변이가 실패를 유발하는지도 확인한다. 로컬 단일 helper·CPU 2·여유 8GiB·자격 3GiB·실행 4GiB 감시는 유지한다.
5. **설치본 확인:** 격리 설치 후 실제 CLI 경로로 같은 표본을 실행하고 소스·의존성·모델 revision·설정을 기록한다. 백업 후 로컬 설치를 교체한다. 산출물 생성이나 테스트 개수만으로 녹취 품질 완료를 선언하지 않는다.

정확한 문제 발언에 대한 원음 검수가 없거나 품질 합격선에 미달하면 품질 관문은 미완이다. 실패 원인·검토 구간·보존된 원음을 제시해 다음 조치의 근거로 삼으며, 다른 모델 출력 하나를 자동 정답으로 채택하지 않는다.
