## 수정·정정한 항목

- 초기 전사문 길이 집계의 중앙값·p90을 표본·계산법이 명확한 재집계로 교체했다. 중복 없는 DB 경로 중 존재하는 64파일, Python `len(text)`, p90 nearest-rank로 중앙값 16,679자·p90 96,884자다. [집계 및 소스 해시](../baseline.json)를 보존했다.
- HF 트렌딩을 탐색하지 않은 최초 24행 초안의 누락을 보완했다. 첫 페이지 30카드를 선별하고 Nemotron Transcribe·소형 신규 후보·실행/양자화 변형을 추가해 총 44행으로 확장했다. HF 전체 모델을 검토했다고 표현하지 않았다.
- Nemotron 30B native MLX의 초기 로컬 추천은 사용자 제약에 따라 철회했다. 활성 4.3B를 전체 34B의 메모리 부담으로 대체하지 않았다.
- T2의 `FLOAT[192]`를 인용 번호로 오인한 검사 결과는 실제 SQL tokenizer/parser 원문을 확인해 `FLOAT[ 192 ]`로 표기했다. 가짜 출처를 추가하거나 검사기를 변경하지 않았다. SQL 실행은 하지 않았다.
- Speechmatics의 할인 표시 가격과 공개 HTML의 기본 요율을 구분해 비교표·비용·상충 설명을 정정했다. 다른 시점의 할인 표시를 무조건 PAYG 기본 가격으로 소급하지 않았다.
- 후처리 기본 모델의 종료 일정은 공식 lifecycle 문서로 보완했다. 모델명 검사용 훅 경고는 모델 존재·가격·종료 일정의 출처로 사용하지 않았다.

## 실행 경계의 예외

허용된 얕은 소스 clone에는 모델 가중치·테스트 모델 **3파일, 합계 19,535,610바이트**가 함께 내려왔다. Buzz의 575,451바이트 BIN, WhisperX의 17,719,103바이트 BIN, Handy의 1,241,056바이트 GGUF다. WhisperX 전처리 계수 `mel_filters.npz` 4,271바이트도 별도 부수 자산이었다. 이 네 모델 관련 바이너리 자산의 합계는 19,539,881바이트다. 별도 모델 다운로드 명령과 모델 추론은 0건이지만 바이너리 전송 0건으로 보고할 수 없다.

초기 담당자 집계가 Handy GGUF를 놓쳤다. 메인이 연구 임시 트리의 확장자 범위를 넓혀 전수 점검하고, 이미 정리된 세 저장소도 고정 commit의 GitHub tree 메타데이터로 재확인했다. 필요한 소스·commit·라이선스 텍스트를 보존한 뒤 해당 세 clone 캐시를 정리했다. 최종 임시 작업 트리 재검사에서는 해당 확장자의 바이너리가 0개였다. 사용자 원본 파일과 기존 모델 저장소는 정리 대상이 아니었다.

초기 표준 라이브러리 집계·수집 일부는 프로젝트 `.venv`를 활성화하지 않은 Python으로 실행했다. `docs/convention.md`를 확인한 뒤 Node.js·표준 셸로 전환했다. 패키지 설치는 없었고 집계법과 원문은 기록에 남겼다.
